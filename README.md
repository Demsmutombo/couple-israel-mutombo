# PDR — ONE MEMORIA

## Expérience numérique des 30 ans de mariage

### Projet de démonstration destiné à Israël Mutombo

---

# 1. VISION DU PROJET

Créer une expérience numérique premium permettant de transformer une cérémonie de renouvellement de vœux célébrant 30 années de mariage en une mémoire numérique structurée, interactive et durable.

Ce projet ne doit PAS être présenté comme un simple site internet de mariage.

Il doit être présenté comme :

> **UNE MÉMOIRE NUMÉRIQUE VIVANTE**

L'objectif est de permettre au couple, à leur famille et aux générations futures de :

* découvrir leur histoire ;
* revivre la cérémonie ;
* regarder les photos ;
* regarder les vidéos ;
* écouter les discours ;
* lire les témoignages ;
* découvrir les personnes présentes ;
* parcourir les 30 années de leur histoire ;
* conserver les souvenirs ;
* laisser des messages pour le futur ;
* accéder à une archive numérique organisée.

Signature :

> **ONE MEMORIA — Vos moments passent. Votre mémoire reste.**

---

# 2. OBJECTIF DE LA MAQUETTE

Cette version est une DEMO destinée à être présentée à Israël Mutombo.

Elle doit donc être :

* extrêmement élégante ;
* émotionnelle ;
* moderne ;
* responsive ;
* fluide ;
* premium ;
* immersive ;
* facile à comprendre ;
* visuellement impressionnante.

IMPORTANT :

La maquette doit utiliser des données de démonstration lorsqu'aucun contenu réel n'a été fourni.

Ne jamais inventer de faits personnels réels concernant Israël ou son épouse.

Utiliser des placeholders clairement identifiés lorsque les contenus réels doivent être ajoutés.

---

# 3. POSITIONNEMENT

OneMemoria ne doit pas être présenté comme :

"un site web de mariage".

Le positionnement doit être :

> **Une plateforme de conservation et de transmission de la mémoire numérique.**

La cérémonie des 30 ans constitue un cas d'utilisation.

Le produit peut ensuite être adapté à :

* mariages ;
* anniversaires ;
* familles ;
* personnalités ;
* artistes ;
* institutions ;
* événements historiques ;
* patrimoine culturel ;
* hommages ;
* héritage familial.

Créer une identité visuelle premium.

Style général :

* élégant ;
* africain contemporain ;
* institutionnel ;
* émotionnel ;
* intemporel ;
* luxueux mais sobre.

Palette recommandée :

* noir profond ;
* blanc cassé ;
* doré élégant ;

* gris très clair.

* animations rapides ;
